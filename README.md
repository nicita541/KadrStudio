# Kadr Studio

Kadr Studio — нативный видеоредактор для Windows на C# и WPF. В интерфейсе нет React, Electron, HTML, встроенного браузера или облачной обработки. Исходники остаются на компьютере пользователя.

## Что уже работает

- импорт MP4, MOV, M4V, MKV, AVI, WMV, WebM, MP3, WAV, M4A, AAC, FLAC, OGG, JPG, PNG, BMP, WebP и TIFF;
- чтение длительности, разрешения, частоты кадров и кодеков через FFprobe;
- медиатека с поиском и миниатюрами;
- стартовый экран с созданием, открытием и списком недавних проектов;
- нативный предпросмотр LibVLC с раздельными видео- и аудиоплеерами и локальным MP4/M4A-кэшем композиции;
- динамические видео- и аудиодорожки: минимум две каждого типа, следующая появляется автоматически;
- перетаскивание файлов на таймлайн;
- свободное перемещение клипов с разрывами, перестановка, обрезка за края, разрезание и удаление (включая контекстное меню);
- изменяемая мышью ширина медиатеки и панели свойств, а также высота таймлайна;
- отдельная громкость и отключение звука для каждого клипа;
- масштабирование таймлайна и горячие клавиши;
- многошаговый локальный анализ видео: сцены, затемнения, тишина, стоп-кадры и структура anime;
- цветные смысловые диапазоны прямо поверх клипов таймлайна;
- уточнение границ отдельными контактными листами локальной vision-модели Ollama без отправки видео в интернет;
- текстовые команды монтажа («удали опенинг», «разрежь в 2:15») в проверяемом черновике с принятием или полным откатом;
- отмена и повтор действий;
- Git-подобные контрольные точки с собственными названиями и восстановлением любой версии проекта;
- сохранение/открытие проектов `.kadr` и локальное автосохранение;
- экспорт MP4 в 480p, 720p и 1080p;
- программное кодирование H.264 и автоматическая проверка NVIDIA NVENC;
- смешивание исходного звука видео с отдельной аудиодорожкой;
- отмена экспорта и отображение прогресса.

## Быстрая сборка на Windows

1. Распакуйте проект в обычную папку без кириллицы в пути, например `F:\KadrStudio`.
2. Запустите `build-release.bat`.
3. Если .NET 10 SDK отсутствует, сценарий предложит установить его через `winget`.
4. Готовая переносимая версия появится в `release\KadrStudio-win-x64`.
5. Архив для переноса появится в `release\KadrStudio-win-x64.zip`.

Для разработки откройте `KadrStudio.sln` в Visual Studio с компонентом «Разработка классических приложений .NET» либо выполните `run-debug.bat`.

## Основные горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Пробел` | Воспроизведение / пауза |
| `S` | Разрезать выбранный клип по курсору |
| `Delete` / `Backspace` | Удалить выбранный клип |
| `←` / `→` | Перейти на один кадр |
| `Shift + ←` / `Shift + →` | Перейти на одну секунду |
| `Ctrl + S` | Сохранить проект |
| `Ctrl + H` | Открыть историю контрольных точек |
| `Ctrl + Z` | Отменить |
| `Ctrl + Y` | Повторить |
| `Ctrl + колесо` | Изменить масштаб таймлайна |

Подробная инструкция находится в [docs/USER_GUIDE.md](docs/USER_GUIDE.md).

## Локальный AI

На этом рабочем компьютере Kadr Studio использует отдельный Ollama на `127.0.0.1:11435` и модель `qwen3-vl:4b-instruct`. Вес модели хранится только в `.ollama\models` внутри проекта (около 3,1 ГБ), не смешивается с обычным хранилищем Ollama на диске C: и не включается в переносимый ZIP.

Откройте раздел «Анализ» слева, выберите видео и диапазон, сформулируйте запрос и оставьте включённым «Уточнить локальным ИИ». FFmpeg вычисляет технические кандидаты, затем vision-модель получает обзор и отдельные увеличенные листы вокруг предполагаемых опенинга, эндинга и финальных сцен. Тот же запрос можно выполнить как черновик монтажа и проверить перед принятием.

## Текущие ограничения

- библиотека переходов, запись экрана и шаблоны ещё не включены;
- смысловые метки локального AI являются помощником и требуют проверки монтажёром;
- предпросмотр использует локальные сегменты композиции и LibVLC; исходники при этом не изменяются;
- проект хранит ссылки на исходники, поэтому исходные медиа нельзя перемещать до завершения монтажа.

## Структура

- `src/Kadr.Core` — точное время, неизменяемое состояние проекта и инварианты;
- `src/Kadr.Application` — транзакции, задания, render plan и предложения автоматизации;
- `src/Kadr.Infrastructure` — SQLite, FFmpeg, кэш и планировщик ресурсов;
- `src/Kadr` — WPF-интерфейс и внешние адаптеры;
- `tools/win-x64` — локальные `ffmpeg.exe` и `ffprobe.exe`;
- `scripts` — сборка и проверка;
- `installer` — сценарий Inno Setup;
- `tests` — модульные, архитектурные, нагрузочные и smoke-проверки;
- `licenses` — уведомления и лицензия FFmpeg.
