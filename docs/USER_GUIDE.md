# Руководство пользователя Kadr Studio

## Проекты

После запуска создайте новый проект, откройте `.kadr` или выберите недавний проект. `Ctrl+S` сохраняет монтаж и ссылки на исходники; сами видео не копируются и не изменяются.

История проекта открывается через `Ctrl+H`. Перед автоматическими операциями создаётся контрольная точка. Старую версию можно восстановить, при этом текущее состояние сначала сохраняется отдельной точкой.

## Медиа и таймлайн

Импортируйте видео, аудио или изображения. Двойной щелчок или перетаскивание добавляет материал на таймлайн:

- видео создаёт связанные клипы V и A, если в исходнике есть звук;
- отдельное аудио попадает только на A-дорожку;
- V-дорожки расположены над A-дорожками, новые V появляются выше, новые A — ниже;
- связь V/A можно разорвать через контекстное меню;
- первое медиа начинается с 00:00, следующие можно положить в выбранную позицию.

Клип перетаскивается за середину и обрезается за края. Привязка включена по умолчанию и притягивает начало/конец клипа к началу проекта, красному playhead, маркерам и краям других клипов; порог остаётся равным 8 экранным пикселям при любом масштабе.

`V` включает Selection, `C` — Razor. В Razor не нужно заранее выделять клип: при наведении появляется перпендикулярная направляющая и таймкод, клик режет связанную V/A-пару, `Alt+клик` разрывает исходную связь и режет только наведённый клип. `Ctrl+K` режет по playhead. `Delete` оставляет освободившееся место, а `Shift+Delete` выполняет Ripple Delete и закрывает его; небезопасное пересечение несвязанного содержимого отклоняется с объяснением. Красный курсор можно вести мышью, не отпуская кнопку. Точки входа/выхода ставятся клавишами `I` и `O`.

Масштаб меняется кнопками или `Ctrl+колесо`. Один общий viewport управляет линейкой, клипами, эскизами, waveform, маркерами и курсором, поэтому горизонтальное перемещение у них всегда синхронно. После последнего элемента остаётся 20 минут свободного пространства.

## Waveform и кадры

Аудио рисуется тонкими вертикальными min/max-линиями: левый канал в верхней половине A-дорожки, правый — в нижней. Тишина равна нулю. Плотность около одной колонки на два физических пикселя; при приближении читается более подробный уровень пирамиды, а не растягивается старая картинка.

Видеоэскизы подгружаются только для видимой части таймлайна и не блокируют интерфейс.

## Предпросмотр

Пробел запускает и приостанавливает просмотр. По умолчанию включено качество 1/2: Kadr Studio фоном создаёт video-only прокси 960×540 в едином кэше производных данных. Пока прокси не готов, используется оригинал. Режим «Оригинал» обходит прокси; экспорт в любом режиме использует только исходные файлы.

Изображение и звук декодируются независимо. Изменение громкости не должно сбрасывать кадр, цветокоррекция — звук, текст — оба декодера. Текст отображается отдельным слоем поверх `WriteableBitmap`, поэтому его можно перемещать и растягивать прямо в плеере.

Разделитель над таймлайном меняет соотношение высоты плеера и дорожек.

Папка и лимит кэша меняются через `Правка → Кэш медиа`. Там же кэш можно безопасно очистить: удаляются только proxy, waveform и эскизы, а проект и исходники остаются нетронутыми.

## ИИ-монтаж

Откройте раздел «ИИ» и напишите задачу обычными словами. Один универсальный агент подходит для фильма, интервью, блога, игры, урока, аниме или записи события; заранее зашитых монтажных сценариев в чате нет. `Enter` отправляет сообщение, `Shift+Enter` добавляет новую строку.

ИИ сначала исследует только нужные диапазоны и показывает план, не меняя таймлайн. Каждый монтажный шаг содержит точный инструмент, точные диапазоны/clip IDs и ссылки на фактические наблюдения. Смысловое действие требует подходящего канала `frames`, `audio`, `transcript` или `all`; структуры таймлайна недостаточно. После утверждения каждое действие разрешено ровно один раз и только с совпадающими аргументами. Изменение диапазона требует пересмотра плана.

Монтаж выполняется в отдельном Agent Draft. Перед завершением агент читает фактический edit log, вызывает проверку gaps/overlaps/синхронизации link-групп и исследует изменённые стыки. Если данных недостаточно, он задаёт вопрос вместо выдуманного результата. Исходная последовательность и исходные файлы не перезаписываются.

Если ИИ не уверен в цели, области или защищённых элементах, в ленте появляется до трёх только блокирующих вопросов с вариантами, рекомендуемым выбором и свободным вводом. Агент не спрашивает то, что уже видно из выделения, playhead, In/Out или проекта. Для точной границы показывается кадр, время и PTS; кнопки `−1 кадр` и `+1 кадр` позволяют выбрать точное место. Информационный запрос завершается ответом по наблюдениям без создания плана или черновика.

Переписка сохраняется вместе с `.kadr`. Технические настройки модели, профиля и стадий анализа выбираются автоматически. Через контекстное меню медиатеки или таймлайна по-прежнему можно закрепить диапазон как обязательный либо запретить его использование.

После импорта лёгкий технический анализ запускается в фоне и приостанавливается на время экспорта. Глубокий vision-анализ запускается по запросу и может быть отменён.

Поиск повторяющихся секций, речи, звука и кадров остаётся доступным агенту как наблюдение и сам по себе ничего не удаляет. Старые preset-DTO читаются из сохранённых проектов для совместимости, но устаревший сценарий не запускается: приложение предложит сформулировать задачу для нового универсального плана.

AI inference работает только через независимый Kadr AI Server. Для разработки на одном ПК desktop подключается к `http://127.0.0.1:5080`; сервер управляет приватным Ollama на `127.0.0.1:11436`, а runtime и модель лежат в `F:\KadrStudioData\AiServer`. Исходные видео и timeline на сервер не передаются: Kadr локально выполняет FFmpeg, готовит нужные кадры/contact sheets и исполняет разрешённые editor tools. Первый раз выполните `scripts\install-ai-server-local.ps1`, затем держите `scripts\run-ai-server.ps1` запущенным независимо от Kadr Studio. Для другого GPU-ПК задайте `KADR_STUDIO_AI_ENDPOINT` и `KADR_STUDIO_AI_API_KEY`; подробности и требования безопасности — в `docs\REMOTE_AI_SERVER.md`.

Desktop не пишет runtime-данные в `%LOCALAPPDATA%` или системный `%TEMP%`. Логи агента, настройки, recovery, cache и временные файлы находятся в `LocalData` внутри корня проекта; папка исключена из Git. При необходимости весь корень можно явно заменить через `KADR_STUDIO_DATA_ROOT`.

Переход добавляется между двумя клипами, которые стоят вплотную. Накладывать их вручную не нужно: редактор сам подготавливает доступный материал по краям и для связанного видео добавляет плавную аудиосклейку.

## Быстрый анализ и текст

Точные команды вроде «вырежи с 0:10 до 0:20» также вводятся в чат. Сначала появляется предложение с перечнем действий, и только после подтверждения создаётся проверяемый черновик.

Во вкладке «Текст» добавляется многострочный текст или импортируется SRT. Двойной щелчок включает редактирование. Рамка в плеере позволяет менять позицию, ширину и высоту; длительность меняется краями текстового клипа T-дорожки.

## Экспорт

Нажмите «Экспорт», выберите разрешение, качество и путь. Создаётся MP4 H.264/AAC. При недоступном NVENC используется программный кодировщик. Исходники не перезаписываются.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| `Пробел` | Воспроизведение / пауза |
| `V` | Selection |
| `C` | Razor |
| `S` | Включить / выключить snapping |
| `Ctrl+K` | Разрезать связанные клипы по playhead |
| `Delete` | Удалить выбранное |
| `Shift+Delete` | Ripple Delete |
| `I` / `O` | Точка входа / выхода |
| `←` / `→` | Один кадр |
| `Shift+←` / `Shift+→` | Одна секунда |
| `Ctrl+S` | Сохранить |
| `Ctrl+H` | История проекта |
| `Ctrl+Z` / `Ctrl+Y` | Отмена / повтор |
| `Ctrl+колесо` | Масштаб таймлайна |
